# Security

Do not publish working access credentials or exploitable details affecting other
owners in public issues. Use the repository's private vulnerability reporting
channel when enabled. If unavailable, ask for a private contact route without
including sensitive details. Never attach raw phone backups or unlock captures.

The experimental opening runner can send an opening command only after explicit
execution enablement, local confirmation and hidden code entry. It has not yet
been tested for physical opening; do not treat it as a supported recovery app. Keep normal recovery
access and avoid firmware changes, resets and code synchronisation experiments.
